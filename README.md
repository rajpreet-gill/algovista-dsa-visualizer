# AlgoVista — Interactive DSA Visualizer

An interactive web application designed to help students understand Data Structures and Algorithms (DSA) through visualizations, explanations, and C++ examples.

🔗 **Live Demo:** https://rajpreet-gill.github.io/algovista-dsa-visualizer/

## ✨ Features

- **DSA Concepts:** Learn fundamental data structures and algorithms through explanations and C++ examples.
- **Graph Visualization:** Explore graph traversal and shortest-path algorithms.
- **BFS:** Visualize Breadth-First Search step by step.
- **DFS:** Understand Depth-First Search through graph traversal.
- **Dijkstra's Algorithm:** Explore shortest-path calculations on weighted graphs.
- **Authentication:** User registration and login using Firebase Authentication.
- **Personal Notes:** Create and manage learning notes using Cloud Firestore.
- **Responsive Interface:** Access the application on desktop and mobile devices.

## 🚀 Getting Started

### Prerequisites

- A modern web browser.
- A code editor, such as Visual Studio Code.
- A Firebase project if you want to use authentication and cloud-based notes.

### Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/rajpreet-gill/algovista-dsa-visualizer.git
   ```

2. Open the project folder:

   ```bash
   cd algovista-dsa-visualizer
   ```

3. Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.

4. If Firebase features require a configured web environment, follow the Firebase setup instructions for your project.
